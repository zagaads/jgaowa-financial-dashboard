# JGAOWA Desktop Live Financial Display Board

Interactive Desktop Financial Display & Analytics Terminal built for **Janapriya Greenwood Apartment Owners Welfare Association (JGAOWA)**.

## Quick Start
1. Double-click `start_financial_board.bat`
2. The dashboard will automatically launch in desktop app mode at `http://localhost:5050`

## Features Included
- **Executive Live Wall Display**: Real-time KPI cards, live clock, ticker tape.
- **23-Month Receipts & Payments**: Complete ledger analysis from April 2024 to February 2026.
- **Lift Modernization Project (Aug 2026)**: Block-by-block collection tracking, vendor payouts, and 65-flat defaulter roster with search and filters.
- **10-Block Painting Project**: Itemized fund utilization and contractor retention tracking.
- **Bank Liquidity Reconciliation**: ICICI Current, ICICI Savings, IDFC First Bank, and Cash in Hand.
- **Interactive Scenario Planner**: What-if simulator with future reserve forecasting.
- **TV / Kiosk Presentation Mode**: Auto-cycling presentation mode for monitors and AGM displays.
